# coffee-machine-resource-tracker
A Python OOP project that simulates a coffee machine with multi-resource tracking. It uses classes, constructors, user input, conditional logic, and encapsulation of resource management to prepare lattes and update remaining resources.
<br>
Topics Covered:
<br>

1. Class and Object
2. Constructor (__init__)
3. Instance Attributes
4. Instance Methods
5. Encapsulation
6. User Input (input())
7. Conditional Statements (if-else)
8. Logical Operators (and)
9. Comparison Operators
10. Arithmetic Assignment Operators (-=)
11. Resource Management
12. While Loop
13. String Formatting (f-strings)
14. State Management
